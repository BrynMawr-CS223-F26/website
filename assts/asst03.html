Due Wednesday October 28, before midnight

1. Set Up

Create a new folder /hw3 whereever your local gitub hw repo is on your computer. To submit this homework, you will add and commit your files, and push them to your homework repo.

2. Zipper

For this problem, you will implement your own linked list in C, and then write a function that merges (or zippers) two linked lists.

2.1. Build it

Define a Node struct and implement basic operations:

  • insert node

  • delete node

  • print list

  • free list

  • whatever else you find helpful

2.2. Manipulate it

Implement a function zipper() that takes two linked lists and merges them into a new linked list, which is then returned.

2.3. Test it

Think of as many edge cases as you can, document them in your code, and ensure your program can handle them. Examples include: lists of unequal sizes, empty lists, etc.

3. Binary Search Tree

For this problem, you will implement a binary search tree (BST). Similar to the first problem, you must implement your own node struct and basic functionality, but this time for a binary search tree. For this problem, this includes implementing a find() function.

Note: Your tree should maintain the binary search tree property when inserting nodes: values smaller than the current node go in the left subtree, and values larger go in the right subtree. You can use strcmp() to compare strings. You do not need to balance the tree.
