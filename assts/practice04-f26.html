Question 1: Threads & Shared Memory

Consider the following C program and then answer the questions relating to it below.

int counter = 0;

void *worker(void *arg) {
    counter++;
    return NULL;
}

int main(void) {
    pthread_t t1, t2;

    pthread_create(&t1, NULL, worker, NULL);
    pthread_create(&t2, NULL, worker, NULL);

    pthread_join(t1, NULL);
    pthread_join(t2, NULL);

    printf("%d\n", counter);
    return 0;
}

  • What value would you expect if both increments execute correctly?

 
 
 
 
 
 

  • Why is the program not guaranteed to produce that value?

 
 
 
 
 
 

  • How could you fix the problem?

 
 
 
 
 
 

Question 2: Mutexes

Consider the following code.

pthread_mutex_t lock =
    PTHREAD_MUTEX_INITIALIZER;

int balance = 100;

void *withdraw(void *arg) {
    pthread_mutex_lock(&lock);

    if (balance >= 30) {
        balance -= 30;
    }

    pthread_mutex_unlock(&lock);
    return NULL;
}

For the following questions, assume three threads execute withdraw() once each.

  • What is the final balance after all three threads finish?

 
 
 
 
 

  • Why is the mutex important?

 
 
 
 
 

  • What would happen if a thread acquired the mutex but never released it?
