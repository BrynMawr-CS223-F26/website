Question 5: Processes and fork()

Consider the following C program. Assume all calls to fork() succeed and that each line of output is written immediately without buffering.

#include <stdio.h>
#include <unistd.h>

int main(void) {
    int x = 1;

    printf("A: %d\n", x);

    pid_t p = fork();

    if (p == 0) {
        x += 2;
        printf("B: %d\n", x);
    } else {
        x += 10;
        printf("C: %d\n", x);

        pid_t q = fork();

        if (q == 0) {
            x += 5;
            printf("E: %d\n", x);
        }
    }

    printf("D: %d\n", x);

    return 0;
}

  • How many total processes execute this program, including the original process?
