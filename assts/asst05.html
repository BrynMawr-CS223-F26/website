Part 1: Multiprocess Array Sum

 
 

Background

Recall that after a call to fork(), the parent and child have separate address spaces. Although the child initially receives a copy of the parent’s data, modifying a variable in one process does not modify that variable in another.

This means that if we want multiple processes to compute parts of a result, we need a way to communicate their results back to the parent. For this problem, you will use pipes.

gcc -O2 -Wall -Wextra -pthread parallel_sum.c -o parallel_sum

 
 
 

The arguments specify the number of elements and number of threads:

./parallel_sum 10000000 4
