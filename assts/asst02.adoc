= 1. Minesweeper

Implement a program, `minesweeper.c`, that generates a minesweeper board.
In link:https://minesweeperonline.com/#[Minesweeper], each cell can either 
contain a bomb or not. Cells without bombs are called safe cells. 

Your program should take three command line arguments -- m, n, and p -- and 
generate an m x n grid of cells where each cell has probability p of containing a 
bomb. To do this, generate a random floating-point value between 0 and 1. If that 
value is less than p, place a bomb in the cell.

Then, your program should print out the grid using X for bombs and . (period) 
for safe cells. 

Finally, your program should output an additional 2D grid with the 
number of neighboring bombs for each cell (above, below, left, right, NW, NE, SW, SE). 

[source,subs="quotes"]
----
$ **make minesweeper**
gcc -g -Wall -Wvla -Werror minesweeper.c -o minesweeper
$ **./minesweeper 3 5 0.4**
X X . . .
. . . . .
. X . . .

X X 1 0 0
3 3 2 0 0
1 X 1 0 0
----

Requirements/Hints:

* Use malloc and free to allocate a 2D array to store the grid.
* You should create dynamic "array of arrays" for your grids.
* Use rand() and srand(time(0)) to create random boards
* Your program must use command line arguments!

Below is example code for seeding and then generating random numbers.


[source,subs="quotes"]
----
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand(time(0));   // do this ONCE

    printf("%d\n", rand());
    printf("%d\n", rand());
    printf("%d\n", rand());
}
----

== Getting started with NCurses                                                           
                                                                                
We will the ncurses library to render text to the screen and respond to user    
input.                                                                          
                                                                                
https://tldp.org/HOWTO/NCURSES-Programming-HOWTO/helloworld.html                
                                                                                
The program below initializes a terminal screen, prints "Hello World!",         
and exits when the user presses any key. All ncurses applications need to       
initialize (`initscr`) and cleanup (`endwin`) the terminal at the start and end 
of the program.                                                                 
                                                                                
[source]                                                                        
----                                                                            
#include <ncurses.h>                                                            
                                                                                
int main()                                                                      
{                                                                               
  initscr();      /* Start curses mode      */                                  
  printw("Hello World !!!");  /* Print Hello World      */                      
  refresh();      /* Print it on to the real screen */                          
  getch();      /* Wait for user input */                                       
  endwin();     /* End curses mode      */                                      
                                                                                
  return 0;                                                                     
}                                                                               
----
