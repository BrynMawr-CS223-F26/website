== Where did the points go?

`scores.c` should add all four scores. Predict the correct total, then compile and run it:

[source, subs="quotes"]
----
gcc -std=c11 -Wall -Wextra -g -O0 scores.c -o scores
./scores
gdb ./scores
----

`-g` includes debugging information. `-O0` disables optimization to keep stepping through source straightforward.

At the GDB prompt, enter:

[source, subs="quotes"]
----
break sum_scores
run
print count
print scores[0]
next
----

A breakpoint pauses execution when the program reaches a location. `next` executes the current source line, 
stepping over any function calls. The displayed source line is normally the line about to execute, not a line 
that has already executed.

Continue with `next` until you are paused on `total += scores[i];`. Then inspect:

[source, subs="quotes"]
----
print i
print scores[i]
print total
next
print total
----

Keep stepping and inspecting until you understand the incorrect result. You can use `list` to see 
nearby source lines and `continue` to finish the run. `quit` exits GDB.

Answer the following questions in a text file:

1. What total did you expect, and what total did the original program print?
2. What index and score did the program use on its first addition? Include the GDB commands and values you observed.
3. Explain the bug. Fix it, exit GDB, recompile, and run again.
4. Give a second input array and its expected total. Change the data in `main` and check your fix, keeping the count consistent.

= Binary Search Tree

For this problem, you will implement a **binary search tree (BST)**. Similar to the first problem, you must implement your own 
node struct and basic functionality, but this time for a binary search tree. For this problem, this includes implementing a `find()` function.

**Note:** Your tree should maintain the binary search tree property when inserting nodes: values smaller than the current 
node go in the left subtree, and values larger go in the right subtree. You can use `strcmp()` to compare strings. You do not 
need to balance the tree.
