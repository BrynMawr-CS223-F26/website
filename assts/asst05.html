Part 1: Multiprocess Array Sum

 

Background

Recall that after a call to fork(), the parent and child have separate address spaces. Although the child initially receives a copy of the parent’s data, modifying a variable in one process does not modify that variable in another.

This means that if we want multiple processes to compute parts of a result, we need a way to communicate their results back to the parent. For this problem, you will use pipes.

 
 

Task

Write a program named process_sum.c that calculates the sum of an integer array using multiple child processes.

Your program should:

  1. Accept an array length N and a number of child processes P as command-line arguments.

  2. Allocate an array of N integers.

  3. Initialize each element using: array[i] = (i % 100) + 1;

  4. Divide the array into P contiguous, nonoverlapping segments.

  5. Create P child processes using fork().

  6. Have each child compute the sum of its assigned segment.

  7. Have each child send its partial sum to the parent through a pipe.

  8. Have the parent collect the partial sums, wait for all children, and compute the total.

  9. Verify the result against a sequential sum calculated by the parent.

Use int64_t for partial sums and totals to avoid integer overflow with large arrays.

Example

For an array containing: 1 2 3 4 5 6 7 8

and two processes:

Processes Assigned Elements Partial Sum

Child 0

1, 2, 3, 4

10

Child 1

5, 6, 7, 8

26

Parent

Combine partial sums

36

The parent should compute 10 + 26 = 36.

 

Requirements

  • Use fork() to create child processes.

  • Use pipe() for interprocess communication.

  • Use waitpid() to reap every child process.

  • Do not use shared memory.

  • Each child must compute only its assigned segment.

  • Close unused pipe descriptors.

  • Handle errors from system calls appropriately.

  • Handle cases where N is not evenly divisible by P.

  • For simplicity, require N >= 1 and 1 ⇐ P ⇐ N.

 

Example execution

gcc -Wall -Wextra -std=c11 -o process_sum process_sum.c
./process_sum 1000000 4

Example output:

Sequential sum: 50500000
Parallel sum:   50500000
Correct: YES

Output wording may differ, but both totals and the correctness result must be clearly displayed.
